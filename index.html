01 — RESEARCH

Data changes.
The questions evolve.

How can we answer questions about connections as a graph changes over time?

I’m interested in the intersection of data management and graph theory: how we represent changing relationships, build useful indexes, and query historical structure.

01 / TEMPORAL

Graphs over time

Representing relationships as timestamped edges, and looking back at the structure within a historical time window.

Temporal data · Historical structure
02 / CONNECTIVITY

Determining whether two vertices are connected in a window’s projected graph, as new edges continue to arrive.

Graph queries · Connected components
03 / INDEXING

Structure for efficiency

Forest-based indexes · Query processing

SIGMOD 2024Proc. ACM Manag. Data · 2(3), Article 157

On Querying Historical Connectivity in Temporal Graphs

Jingyi Song, Dong Wen, Lantian Xu, Lu Qin, Wenjie Zhang, Xuemin Lin

Given a time window and two vertices, are they connected in the graph formed by that window’s edges? This work develops a forest-based index for efficient historical and sliding-window connectivity queries.
